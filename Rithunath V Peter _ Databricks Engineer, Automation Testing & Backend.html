About me

I studied Computer Science and Engineering, then started my career in automation testing. Writing Selenium and Playwright suites, running load tests with Locust and scanning with OWASP ZAP taught me how software fails, and what it takes to make it dependable.

That curiosity pulled me toward the systems behind the tests: Spring Boot and Node.js backends through my Java Full Stack training, and now data pipelines with Databricks, SQL and PySpark at TCS. I like understanding a product end to end, from the code that builds it to the checks that prove it works.

I learn quickly, work in a disciplined way, and ask for feedback early.
